# Odyssey CYOA — Advanced English II: Semester 1 Final Project


This repository contains a polished, single-player choose-your-own-adventure web app that dramatizes choices from *The Odyssey* from three perspectives: Odysseus, Penelope, and Athena. It emphasizes the themes of fate vs. free will, home & identity, and the costs of pride.


**What's included**
- `src/App.jsx` — main React component (UI, game logic, nodes)
- `src/main.jsx` — React entry
- `index.html`, `package.json`, `vite.config.js` — minimal Vite setup
- `src/index.css` — Tailwind setup
- `ARTIST_STATEMENT.md` — 250-word (or less) statement
